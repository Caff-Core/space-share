# Space Share

Direct local-network file sharing between desktop (Tauri 2) and mobile (Expo) devices. No accounts, no cloud, no internet required at runtime.

- Spec: [`docs/FILE_SHARING_AGENT_PLAN.md`](docs/FILE_SHARING_AGENT_PLAN.md)
- Progress tracker: [`docs/IMPLEMENTATION_PHASES.md`](docs/IMPLEMENTATION_PHASES.md)
- Platform status: [`docs/platform-support.md`](docs/platform-support.md)

Current track: Linux desktop + Android. Windows, macOS and iOS are deferred.
